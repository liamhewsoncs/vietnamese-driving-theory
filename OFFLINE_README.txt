VIETNAMESE DRIVING THEORY TEST — OFFLINE QUIZ
==============================================

HOW TO START

1. Extract the entire ZIP file.
2. Keep all included files and folders together.
3. Open index.html in a modern web browser.

No installation, account, or internet connection is required. Progress and
preferences are saved in that browser's local storage.

IMPORTANT ACCURACY NOTICE

Vietnamese Driving Theory Test is an independent study aid, not an official
Vietnamese licensing app.
Its questions are based on the 2025 Cục Cảnh sát giao thông (CSGT) 600-question
driving-theory bank. Many English strings began as machine translations and
have not received expert legal or technical review. Always compare wording,
answers, and current exam rules with the official Vietnamese material.

Official source links and project documentation are available in the GitHub
repository from which this release was downloaded.
